## 🇬🇧 English

### 👋 About This Project

Welcome to my SQL Practice Problems repository! 🚀

This project contains my personal SQL solutions to exercises from *SQL Practice Problems* by Sylvia Moestl Vasilik. Using the **Northwind sample database**, I practise writing queries, improve my database skills, and develop practical problem-solving abilities.

My goal is to strengthen my SQL Server knowledge through hands-on practice and build a portfolio of SQL work.

### 🎯 Project Goals

- 💡 Strengthen SQL querying skills
- 🗃️ Practise working with relational databases
- 🔍 Improve data filtering and retrieval
- 🔗 Understand relationships between tables
- 💻 Build practical SQL Server experience
- 📁 Document and organize SQL solutions on GitHub

### 🧰 Tools & Technologies

| Tool | Description |
|---|---|
| 🛠️ SQL Server | Relational database management system |
| 💻 SSMS | SQL Server Management Studio |
| 🗃️ Northwind | Sample database for query practice |
| 🐙 GitHub | Project documentation and version control |

### 🛠️ SQL Topics

- `SELECT`, `WHERE`, `ORDER BY`, `DISTINCT`, `TOP`
- Filtering with `LIKE`, `IN`, `AND`, and `OR`
- Aggregate functions: `COUNT`, `MIN`, `AVG`
- Grouping data with `GROUP BY`
- Table relationships using `INNER JOIN` and `LEFT JOIN`
- Subqueries and related-record analysis
- Date conversion and date functions
- Calculated columns and conditional expressions
- `IIF` and `IS NULL`

### ▶️ How to Run the Queries

1. Open `northwind_practice_problems.sql` in SQL Server Management Studio (SSMS).
2. Make sure the Northwind sample database is available on your SQL Server instance.
3. Execute the queries and review the results.
4. Explore the code to understand different approaches to solving SQL problems.

### 📚 Learning Reference

**Book:** *SQL Practice Problems*  
**Author:** Sylvia Moestl Vasilik

This repository presents my own SQL solutions for learning and portfolio purposes. It does not reproduce the book's question text.
