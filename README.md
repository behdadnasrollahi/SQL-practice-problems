# SQL Practice Problems | Northwind

A collection of my personal SQL Server practice solutions using the Northwind sample database. The exercises are based on *SQL Practice Problems* and are intended to strengthen practical querying skills through hands-on practice.

## Current progress

- Exercises covered so far: **1–31**
- Topics include introductory queries and intermediate querying techniques.
- Some exercises include more than one approach for practice and comparison.
- This repository will be updated as I continue working through the book.

## Skills practiced so far

- `SELECT`, `WHERE`, `ORDER BY`, `DISTINCT`, `TOP`
- Filtering with `LIKE`, `IN`, `AND`, and `OR`
- Aggregate functions such as `COUNT`, `MIN`, and `AVG`
- `GROUP BY` and sorting aggregated results
- `INNER JOIN` and `LEFT JOIN`
- Subqueries and checking for missing related records
- Date conversion and date functions
- Calculated columns, `IIF`, and `IS NULL`

## How to run

1. Open the `.sql` file in SQL Server Management Studio (SSMS).
2. Make sure the Northwind sample database is installed on your SQL Server instance.
3. Run the queries against Northwind. Some exercises depend on the database objects and sample data being available.
